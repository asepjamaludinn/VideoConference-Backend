# 📹 Real-Time Video Conferencing & Chat Platform

Sebuah platform video conferencing dan chatting real-time yang dirancang untuk mendukung hingga **100 pengguna per sesi**. Proyek ini dikembangkan oleh sebuah startup dengan tujuan menyediakan solusi komunikasi digital yang stabil, aman, dan mudah digunakan, baik untuk **meeting online**, **kelas virtual**, maupun **webinar**.

---

## 🚀 Fitur Utama

- 🎥 **Streaming Video** berkualitas tinggi hingga **1080p**
- 💬 **Chat Real-Time** dalam sesi video yang sama (teks)
- 🖥️ **Screen Sharing** untuk presentasi dan kolaborasi
- 🎛️ **Manajemen Sesi**:
  - Join/Leave session
  - Mute/Unmute user
  - Host & participant control
- 🔐 **Keamanan** untuk melindungi data pengguna dan sesi
